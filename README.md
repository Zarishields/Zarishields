# Zarishields

**Check if a sanitary pad is genuine and safe before you use it.**

**Live demo:** https://zarishields.github.io/Zarishields/


## The problem

Fake and substandard sanitary pads are sold in markets and shops across Nigeria, and buyers have no easy way to check a pad before use. I have had a reaction from a fake pad, and so have my sisters and friends. The risk is highest for women and girls without smartphones or data.

## How it works

1. **Verify the pack.** Each pack carries a unique scratch-card PIN. The user checks it by app, SMS or USSD and gets: verified, check with care, or not found.
2. **Screen the pad.** A low-cost pH strip adds a physical check. It is a screening step alongside the PIN check, not proof on its own.
3. **Report fakes.** Users report suspected counterfeits so others can be warned.

## Current status

This repository holds a clickable prototype (`index.html`) that simulates these flows using sample data. It is not yet connected to a live database, SMS or USSD network. Demo codes: `ZS-1001-AAAA`, `ZS-2002-BBBB`, `ZS-9999-XXXX`.
